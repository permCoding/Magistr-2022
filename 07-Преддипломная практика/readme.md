### Преддипломная практика  

`Преддипломная практика` посвящена методике проектирования ИС, управляемого функциональностью - `Functional-First Design`.  

Предполагается, что:  

- на первом этапе детально проектируется **что именно должна делать система**  
- затем **на каких структурах данных** она это делает и  
- только потом **как это будет технически организовано** (архитектура)  

---  

**Структура отчета** по Преддипломной практике:  

Титульный лист  
Оглавление  
Введение  

1. Анализ предметной области  

2. Проектирование функционала информационной системы  
   2.1. Моделирование требований (UML Use Case Diagram)  
   2.2. Определение операций над данными (CRUD-матрица)  
   2.3. Проектирование логики взаимодействия (UML Sequence Diagram, при необходимости)  
   2.4. Проектирование алгоритмов (UML Activity Diagram / Блок-схемы)  

3. Проектирование структуры данных и базы данных  
   3.1. Разработка диаграммы классов (UML Class Diagram)  
   3.2. Разработка схемы базы данных  

Заключение  
Список использованных источников  
Приложения  

---  

Дневник практики (это отдельный документ, со своей нумерацией).  
**Оформление Отчёта и Дневника** аналогичны оформлению Очёта и Дневника в методичке для бакалавриата.  
Общий объём отчёта **примерно 25 страниц**.  

---  

Содержание практики **может быть изменено, сокращено или дополнено**, в зависимости от решаемых задач моделирования, проектирования ИС и используемых технологий.  

Вопросы **архитектурного моделирования ИС** выносятся на этап выполнения ВКР.  

Если в проекте **не используется база данных**, то можно подробнее остановиться на применяемых в реализации форматов для хранения данных – это могут быть структурированные файлы в формате `csv`, `xml`, `yaml`, `json`, `docx`, `ini` или других форматов.  

Рекомендуется в **список источников** включать актуальные работы по направлению ВКР в количестве **от 10 до 15 пунктов**. Это могут быть законодательные акты, научные статьи, учебники и учебные пособия, стандарты и спецификации.  

---  

В Пункте 3.1 - раскройте сущности предметной области, их атрибуты и связи; раскройте методы классов.  

В пункте 3.2 - постройте ER-диаграммы (логическую и физическую модель), сделайте обоснование выбора СУБД (SQLite, PostgreSQL, ...), приведите описание нормализации и примеры DDL-скриптов - достаточно именно SQL-скриптов (Data Definition Language - CREATE TABLE, PRIMARY KEY, FOREIGN KEY, индексы, CREATE INDEX, CREATE VIEW) по определению структуры таблиц, созданию индексов и разработке представлений. Операции по манипулированию данными (DML) можно оставить на этап выполнения ВКР.
