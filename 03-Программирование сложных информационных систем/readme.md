
Основные архитектурные стили:  

- монолитная  
- клиент-серверная  
- микросервисная  

В монолите - UI + бизнес-логика + хранилище данных (json, csv, БД) всё в одном.  
В клиент-сервере - деление на слои: сервер выполняет бизнес-логику, взаимодействует с хранилищем, пролучает от клиента запросы и возвращает html, json, на клиенте только интерфейс (отображение данных и возможность отправлять запросы).  
В микросервисной — серверная часть разбита на несколько независимых сервисов (каждый со своим хранилищем, API, языком) и сервисы запускаются отдельно, меняются и масштабируются независимо.
